## The Critical Transition

You've completed all planning with Claude Chat. Now you're transitioning to Claude Code for implementation.

| Before This Point | After This Point |
|------------------|------------------|
| Claude Chat (web) | Claude Code (CLI) |
| Exploration, iteration | Implementation |
| Document generation | File editing, testing |

:::warning Do Not Skip This Setup
Without proper environment configuration, Claude Code won't have the context needed to implement your design correctly.
:::

## Step 1: Create Next.js Project

```bash
npx create-next-app@latest my-saas-project \
  --typescript --tailwind --eslint --app --src-dir
cd my-saas-project
```

## Step 2: Initialize Git

```bash
git init
git add .
git commit -m "Initial Next.js project setup"
```

## Step 3: Create CLAUDE.md

<TemplateDownload
  name="CLAUDE.md Template"
  file="claude-md"
  description="Project context template for Claude Code"
/>

The CLAUDE.md file provides Claude Code with project context:

```markdown
# CLAUDE.md

## Project Overview
[Brief description from design-brief.md]

## Technology Stack
- Frontend: Next.js 14+ with App Router
- Styling: Tailwind CSS
- Database: Supabase (PostgreSQL + Auth + Storage)
- AI: Claude API
- Payments: Stripe

## Project Structure
[From architecture.md]

## Code Standards
- TypeScript strict mode
- ESLint + Prettier
- Vitest for testing

## Database Conventions
- Tables use snake_case
- All tables have RLS enabled
- Foreign keys with ON DELETE CASCADE

## Key Commands
- `npm run dev` - Start development server
- `npm run build` - Production build
- `npm run test` - Run tests
- `npm run lint` - Run ESLint

## Vocabulary
[Extract canonical terms from design-brief.md]

## Current Sprint Focus
- Currently working on: M1 - Project Setup
- Next milestone: M2 - Design System

## Project Artifacts
- `docs/design-brief.md` - Product vision and vocabulary
- `docs/ux-package.md` - User flows and screens
- `docs/ui-system.md` - Component specifications
- `docs/architecture.md` - Technical architecture
- `docs/build-contract.md` - Implementation reference
```

## Step 4: Set Up Documentation Structure

```bash
mkdir -p docs/specs
```

Place your artifacts:
```
docs/
├── design-brief.md
├── ux-package.md
├── ui-system.md
├── architecture.md
├── build-contract.md
└── specs/          # For SPEC documents
```

## Step 5: Initial Commit

```bash
git add .
git commit -m "Add CLAUDE.md and documentation structure"
```

## Step 6: Install Claude Code

```bash
npm install -g @anthropic-ai/claude-code
claude --version
```

## Step 7: Verify Setup

Run Claude Code and test:

```bash
claude "Read CLAUDE.md and summarize the project"
```

Claude should correctly describe your project's purpose, tech stack, and key terminology.

## Environment Ready Checklist

| Item | Verification |
|------|--------------|
| Project created | Next.js with TypeScript, Tailwind, App Router |
| Git initialized | At least one commit |
| CLAUDE.md exists | At project root with project details |
| docs/ folder | Contains all design artifacts |
| docs/specs/ folder | Empty, ready for SPECs |
| Claude Code installed | `claude --version` works |
| Context test passed | Claude can summarize your project |

:::tip You're Ready
If all items pass, you're ready to begin the Build phase. Start with Milestone 1: Project Setup.
:::
