## Why Score Opportunities?

Gut feelings are unreliable. You'll naturally gravitate toward ideas you find exciting, not necessarily ideas that will succeed. A structured scoring framework forces objectivity.

## The Opportunity Scoring Framework

Score each dimension from 1-5, where 5 is the best:

### 1. Market Opportunity (Weight: 25%)

| Score | Criteria |
|-------|----------|
| 5 | Large market, growing rapidly, underserved |
| 4 | Good market size, moderate growth |
| 3 | Niche market, stable demand |
| 2 | Small market or declining |
| 1 | No clear market or oversaturated |

### 2. Problem Severity (Weight: 25%)

| Score | Criteria |
|-------|----------|
| 5 | "Hair on fire" problem—urgent, expensive, frequent |
| 4 | Significant pain, people actively seeking solutions |
| 3 | Nice-to-have, moderate pain |
| 2 | Low pain, many workarounds exist |
| 1 | Problem doesn't really exist |

### 3. Competitive Landscape (Weight: 15%)

| Score | Criteria |
|-------|----------|
| 5 | No direct competitors, clear differentiation |
| 4 | Few competitors, strong differentiation possible |
| 3 | Moderate competition, can differentiate |
| 2 | Crowded market, differentiation unclear |
| 1 | Dominated by well-funded players |

### 4. Execution Feasibility (Weight: 20%)

| Score | Criteria |
|-------|----------|
| 5 | Can build MVP in weeks, low technical risk |
| 4 | Achievable in 1-2 months, manageable complexity |
| 3 | 3-6 months, requires learning new skills |
| 2 | 6+ months, significant technical challenges |
| 1 | Requires resources beyond your reach |

### 5. Founder-Market Fit (Weight: 15%)

| Score | Criteria |
|-------|----------|
| 5 | Deep domain expertise, personal experience with problem |
| 4 | Good understanding, adjacent experience |
| 3 | Can learn quickly, motivated |
| 2 | Little knowledge, weak motivation |
| 1 | No connection to market or users |

## Comparing Multiple Opportunities

If you have several ideas, score each one independently:

| Dimension | Idea A | Idea B | Idea C |
|-----------|--------|--------|--------|
| Market Opportunity | | | |
| Problem Severity | | | |
| Competitive Landscape | | | |
| Execution Feasibility | | | |
| Founder-Market Fit | | | |
| **Weighted Total** | | | |

:::tip Don't Force It
If no opportunity scores above 3.0, don't proceed. Go back to ideation. It's better to find a stronger opportunity than to build something destined to struggle.
:::

## Interpretation Guide

| Weighted Score | Assessment | Action |
|----------------|------------|--------|
| 4.0 - 5.0 | Strong opportunity | Proceed with confidence |
| 3.0 - 3.9 | Moderate opportunity | Proceed with awareness of risks |
| 2.0 - 2.9 | Weak opportunity | Consider pivoting or passing |
| Below 2.0 | Poor opportunity | Pass and find another idea |
