# MOAI Overview

The **Milestone-Oriented AI Integration (MOAI)** framework structures the Build phase into manageable, verifiable milestones. Each milestone has clear deliverables, quality gates, and acceptance criteria.

<details>
<summary>💡 Learn More: Why Milestones Matter</summary>

Large implementation projects fail for predictable reasons:
- **Scope creep** — features grow beyond what was planned
- **Context loss** — AI loses track of the bigger picture over long sessions
- **Quality drift** — standards erode as deadlines approach

MOAI addresses these by:
1. **Fixed scope per milestone** — Each milestone has explicit, unchanging deliverables
2. **Fresh context per milestone** — Start each milestone with clean context and the Build Contract
3. **Quality gates** — No milestone is complete until all quality criteria pass

The 11-milestone structure (M1-M11) is designed so each can be completed in 1-3 focused sessions.

</details>
