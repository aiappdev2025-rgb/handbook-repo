The Prompt Builder helps you generate effective prompts for Claude Code based on the MOAI methodology. Select a phase, milestone, and prompt template, then fill in your project-specific variables.

## How to Use

1. **Select a Phase** - Choose which phase of MOAI you're currently in
2. **Select a Milestone** - Pick the specific milestone you're working on
3. **Select a Prompt Template** - Choose the type of task you need help with
4. **Fill Variables** - Customize the prompt with your project details
5. **Copy & Paste** - Copy the generated prompt into Claude Code

## Tips for Best Results

- **Be specific** with your variable values - the more context, the better the output
- **Paste existing specs** where indicated for consistent implementations
- **Run prompts sequentially** within a milestone for coherent results
- **Iterate** by feeding outputs back as inputs for subsequent prompts
