# Appendix C: Session Checklist

This appendix provides checklists for session start, during session, and session end. Print or bookmark these for quick reference.

### Session Start Checklist

- [ ] Claude reads CLAUDE.md (automatic)
- [ ] Ask Claude to read docs/STATE.md
- [ ] Ask Claude to read docs/TASKS.md
- [ ] Confirm current task and milestone
- [ ] Check for any blockers from last session

### During Session Checklist

- [ ] Focus on one task at a time
- [ ] Check /status periodically
- [ ] Verify each task before marking complete
- [ ] Commit after each completed task
- [ ] Consider clearing if context > 80K tokens

### Session End Checklist

- [ ] All work committed to Git
- [ ] docs/STATE.md updated with session summary
- [ ] docs/TASKS.md updated with completion status
- [ ] Any learnings added to docs/MEMORY.md
- [ ] Final commit: session-end message
- [ ] Clear context: /clear
