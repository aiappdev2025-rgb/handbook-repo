# Appendix E: Command Reference

This appendix provides quick reference tables for Claude Code commands and useful Git commands.

## Claude Code Commands

| Command | Purpose | When to Use |
| --- | --- | --- |
| /clear | Reset conversation context | After task complete, at session end |
| /status | Show current token usage | Periodically during work |
| /config | Open configuration | To adjust settings |
| /help | Show available commands | When you forget a command |

## Useful Git Commands

| Command | Purpose |
| --- | --- |
| git status | See changed files |
| git add . | Stage all changes |
| git commit -m "msg" | Commit with message |
| git log --oneline -10 | See recent commits |
| git diff | See unstaged changes |
