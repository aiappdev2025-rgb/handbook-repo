# 6. Skills vs CLAUDE.md

In this chapter, you'll learn the distinction between CLAUDE.md and Skills. Both provide context to Claude Code, but they serve different purposes. By the end of this chapter, you'll know when to use each for optimal organization.

## 6.1 When to Use Each

Claude Code supports both CLAUDE.md and Skills. Understanding when to use each helps you organize project-specific vs reusable knowledge:

| Use CLAUDE.md For | Use Skills For |
| --- | --- |
| Project-specific context | Reusable patterns across projects |
| Current state and tasks | Technology-specific knowledge |
| Team conventions | Tool integrations (MCP servers) |
| This project's architecture | Your coding style preferences |

> **Expected Outcome**
>
> **What you should understand:** The difference between project-specific context (CLAUDE.md) and reusable knowledge (Skills).
>
> **How to validate:** You can decide whether new information belongs in CLAUDE.md or should be a Skill.
>
> **Next:** Chapter 7 — Set up your initial project documentation.

## Chapter 6 Summary

- CLAUDE.md: Project-specific context, state, conventions, and architecture
- Skills: Reusable patterns, technology knowledge, tool integrations, personal preferences
- Use CLAUDE.md for "this project"; use Skills for "all projects"
