```text

  
  ROLE
Full-Stack Developer building user management for admin console.

CONTEXT
Admin layout is complete (Prompt 7.2).
Need to build the core user management functionality.
This is the most-used part of the admin console.

OBJECTIVE
Create user list, search, and detail view with basic actions.

REQUIREMENTS

1. User list page (src/app/admin/users/page.tsx):
- Server Component with pagination (20 per page)
- Search by email or name
- Filter by: subscription status, role, signup date range
- Sort by: created_at, email, last_sign_in
- Table columns: Avatar, Email, Name, Role, Status, Joined, Actions
- Click row to go to user detail

2. User queries (src/lib/admin/queries/users.ts):
- getUsers(options): Paginated, filtered, sorted user list
- getUserById(id): Full user details with subscription info
- searchUsers(query): Quick search by email/name
- getUserStats(): Counts for dashboard

3. User detail page (src/app/admin/users/[id]/page.tsx):
- Profile section: avatar, name, email, role, signup date
- Subscription section: current plan, status, renewal date
- Activity section: recent actions (from your activity tracking)
- Admin notes section: view/add notes about this user
- Actions: Edit profile, Reset password, Disable account

4. User actions (src/app/admin/users/actions.ts):
- updateUserProfile(userId, data): Edit name, avatar_url
- sendPasswordReset(userId): Trigger password reset email
- disableUser(userId): Set account to disabled status
- enableUser(userId): Re-enable disabled account
- addAdminNote(userId, content): Add a note to user
- All actions log to audit log

5. User components (src/components/admin/users/):
- UserTable: Sortable, clickable rows
- UserFilters: Search, status, role, date filters
- UserCard: Profile display for detail page
- UserActions: Action buttons with confirmations
- AdminNotesSection: Notes list with add form

QUALITY STANDARDS
All actions require confirmation dialog
All actions create audit log entries
Search is debounced (300ms)
Pagination uses URL params (shareable)
Error states handled (user not found, etc.)
No function exceeds 30 lines

DELIVERABLES
1. src/app/admin/users/page.tsx
2. src/app/admin/users/[id]/page.tsx
3. src/app/admin/users/actions.ts
4. src/lib/admin/queries/users.ts
5. src/components/admin/users/ (all components)

VERIFICATION
1. User list loads with pagination
2. Search finds user by email
3. Filters narrow results correctly
4. Click user → detail page shows
5. Add admin note → appears in list
6. Password reset → email sent (check Supabase logs)
7. Disable user → status changes, audit log created
```
