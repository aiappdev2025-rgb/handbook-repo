```text

  
  ROLE
QA Engineer writing end-to-end tests.

CONTEXT
Project: {{productName}}
Test infrastructure ready (Prompt 11.1).
Focus on critical user journeys.

OBJECTIVE
Write E2E tests for the most important user flows.

REQUIREMENTS

1. Authentication flow (e2e/auth.spec.ts):
- User can sign up with valid credentials
- User can log in with existing account
- User is redirected to dashboard after login
- User can log out
- Protected routes redirect to login

2. Core feature flow (e2e/{{feature}}.spec.ts):
- User can create new {{entity}}
- User can view {{entity}} details
- User can edit existing {{entity}}
- User can delete {{entity}}
- Data persists after page refresh

3. Payment flow (e2e/payments.spec.ts):
- User can view pricing page
- Checkout redirects to Stripe (mock in test)
- Success page displays after payment
- Billing page shows subscription status

4. Test data management:
- Use test-specific database or clean between tests
- Create test user fixtures
- Don't share state between tests

VERIFICATION
All E2E tests pass
Tests complete in under 5 minutes
Tests are deterministic (no flakes)
```
