```text

  
  ROLE
Frontend Developer auditing loading states.

CONTEXT
Project: {{productName}}
Error boundaries done (Prompt 10.1).
Need consistent loading experience.

OBJECTIVE
Audit and improve loading states throughout the app.

REQUIREMENTS

1. Page loading states:
- Create loading.tsx for each route group
- Use skeleton components matching content layout
- Avoid layout shift when content loads

2. Component loading states:
- Buttons: Disabled + spinner during actions
- Forms: Submit button shows loading
- Lists: Skeleton cards while fetching
- Images: Blur placeholder or skeleton

3. Suspense boundaries:
- Wrap async components in Suspense
- Provide appropriate fallback UI
- Strategic placement (not too many, not too few)

4. Loading indicators:
- Spinner component (consistent style)
- Progress bar for longer operations
- Optimistic updates where appropriate

5. Performance considerations:
- Don't show loading for fast operations (< 200ms)
- Use transitions for state changes
- Preload data where possible

VERIFICATION
Throttle network in DevTools — loading states appear
No blank screens during data fetching
No layout shifts on load
```
