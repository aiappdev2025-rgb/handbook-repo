```text

  
  ROLE
QA Engineer auditing edge cases.

CONTEXT
Project: {{productName}}
Empty states done (Prompt 10.3).
Need to handle unusual but valid scenarios.

OBJECTIVE
Identify and handle edge cases throughout the app.

REQUIREMENTS

1. Input edge cases:
- Very long text inputs
- Special characters and unicode
- Empty strings vs null
- Maximum file sizes
- Invalid date ranges

2. Data edge cases:
- Deleted related records
- Concurrent modifications
- Very large datasets (pagination)
- Very old dates

3. User flow edge cases:
- Back button after form submit
- Double-click on submit
- Session expiry during action
- Multiple tabs with same form

4. Network edge cases:
- Slow connections
- Request timeout
- Offline mode (if applicable)
- Partial responses

5. Handle gracefully:
- Add validation for edge inputs
- Disable buttons during submission
- Show appropriate feedback
- Log unexpected scenarios

VERIFICATION
Test each edge case manually
No crashes or unhandled errors
User gets helpful feedback in all cases
```
