```text

  
  ROLE
Database Engineer adding admin functionality tables.

CONTEXT
Project: {{productName}}
Core tables already exist (profiles, etc.).
Adding tables to support admin console functionality.

OBJECTIVE
Create migration for admin-related database tables.

REQUIREMENTS

1. Add role column to profiles table:
- role: text, default 'user'
- Valid values: 'user', 'admin', 'super_admin'
- Add check constraint for valid values

2. Create admin_audit_logs table:
- id: uuid primary key
- admin_id: uuid references profiles(id)
- action: text not null (e.g., 'user.view', 'user.disable')
- target_type: text (e.g., 'user', 'subscription')
- target_id: uuid
- details: jsonb (additional context)
- ip_address: text
- created_at: timestamptz default now()

3. Create admin_notes table:
- id: uuid primary key
- admin_id: uuid references profiles(id)
- target_user_id: uuid references profiles(id)
- content: text not null
- created_at: timestamptz default now()
- updated_at: timestamptz default now()

4. Create system_settings table:
- key: text primary key
- value: text not null
- description: text
- is_sensitive: boolean default false
- updated_at: timestamptz default now()
- updated_by: uuid references profiles(id)

5. RLS Policies:
- admin_audit_logs: Only admins can SELECT, only system can INSERT
- admin_notes: Only admins can SELECT/INSERT/UPDATE/DELETE
- system_settings: Only admins can SELECT, only super_admins can UPDATE

6. Create helper function to check admin role:
- is_admin(): returns boolean
- Checks if current user has role 'admin' or 'super_admin'

7. Update profiles RLS:
- Admins can SELECT all profiles
- Regular users can still only see their own

QUALITY STANDARDS
Migration is idempotent
All tables have RLS enabled
Indexes on admin_id and target_id columns
Foreign keys have ON DELETE behavior defined

DELIVERABLES
1. supabase/migrations/[timestamp]_create_admin_tables.sql
2. Updated src/types/database.ts with admin types

VERIFICATION
1. Run: npx supabase db push
2. Verify tables in Dashboard
3. Test is_admin() function with different user roles
4. Verify non-admin cannot query admin_audit_logs
```
