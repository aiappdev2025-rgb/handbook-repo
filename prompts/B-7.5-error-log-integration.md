```text

  
  ROLE
Full-Stack Developer integrating error tracking into admin console.

CONTEXT
User and subscription viewing complete.
Integrating with error tracking service for visibility into production errors.
Using {{Sentry / your error tracking service}}.

OBJECTIVE
Create error log viewing in admin console.

REQUIREMENTS

1. Set up error tracking (if not already done):
- Install @sentry/nextjs (or your service's SDK)
- Configure in next.config.js
- Add SENTRY_DSN to environment variables
- Create sentry.client.config.ts and sentry.server.config.ts

2. Create API route for fetching errors (src/app/api/admin/errors/route.ts):
- GET: Fetch recent errors from Sentry API
- Requires admin authentication
- Query params: limit, cursor (for pagination)
- Returns: issues with count, last_seen, first_seen, title

3. Error log page (src/app/admin/errors/page.tsx):
- List of recent errors with severity indicator
- For each error: title, count, last occurrence, affected users
- Click to expand: stack trace preview, affected user IDs
- Link to full details in Sentry dashboard
- Filter by: severity, resolved status, date range

4. Error components (src/components/admin/errors/):
- ErrorList: Expandable error items
- ErrorItem: Single error with expand/collapse
- ErrorSeverityBadge: Color-coded severity
- StackTracePreview: Formatted stack trace snippet

5. Dashboard integration:
- Add error count widget to admin dashboard
- Show unresolved error count
- Alert style if > 10 unresolved errors

Alternative if not using Sentry:
- Create local error_logs table
- Log errors from API routes and server actions
- Query and display from database

QUALITY STANDARDS
Error fetching is paginated (don't load all at once)
Stack traces truncated in preview (full in expanded)
No sensitive data in error details exposed
Sentry API key stored securely (env var)

DELIVERABLES
1. Error tracking SDK configuration
2. src/app/api/admin/errors/route.ts
3. src/app/admin/errors/page.tsx
4. src/components/admin/errors/ (all components)
5. Updated admin dashboard with error widget

VERIFICATION
1. Trigger a test error in the app
2. Error appears in admin errors page
3. Click to expand shows stack trace
4. Link to Sentry opens correct issue
5. Dashboard shows error count
```
