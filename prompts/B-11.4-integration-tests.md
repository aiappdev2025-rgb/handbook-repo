```text

  
  ROLE
Backend Developer writing integration tests.

CONTEXT
Project: {{productName}}
Unit tests complete (Prompt 11.3).
Need integration tests for API routes.

OBJECTIVE
Write integration tests for API routes and server actions.

REQUIREMENTS

1. API route tests (src/app/api/__tests__/):
- Test successful responses
- Test error responses (400, 401, 403, 404, 500)
- Test with valid/invalid auth tokens
- Test request body validation

2. Server action tests:
- Test actions return expected data
- Test authorization checks work
- Test validation errors are returned
- Test side effects (database writes)

3. Database integration:
- Use test database or transaction rollback
- Test RLS policies are enforced
- Test queries return expected data

4. Webhook tests (if applicable):
- Test with valid Stripe signatures
- Test invalid signatures are rejected
- Test event handling updates database

5. Mock external services:
- Mock Stripe API calls
- Mock email sending
- Use MSW for HTTP mocking

VERIFICATION
All integration tests pass
Tests don't require external services
Run: npm run test:coverage — target ≥ 80%
```
