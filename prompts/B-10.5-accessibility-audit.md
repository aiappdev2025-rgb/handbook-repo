```text

  
  ROLE
Accessibility Specialist auditing WCAG compliance.

CONTEXT
Project: {{productName}}
Edge cases handled (Prompt 10.4).
Need to meet WCAG 2.1 AA standards.

OBJECTIVE
Audit and fix accessibility issues.

REQUIREMENTS

1. Keyboard navigation:
- All interactive elements focusable
- Logical tab order
- Focus visible indicator
- Skip links for main content
- No keyboard traps

2. Screen reader support:
- Semantic HTML (headings, landmarks)
- Alt text for images
- ARIA labels where needed
- Form labels associated with inputs
- Live regions for dynamic content

3. Visual accessibility:
- Color contrast ratio ≥ 4.5:1
- Don't rely on color alone
- Text resizable to 200%
- No content hidden at zoom

4. Forms accessibility:
- Labels for all inputs
- Error messages linked to fields
- Required fields indicated
- Instructions before fields

5. Testing tools:
- Run axe-core in browser
- Test with VoiceOver/NVDA
- Lighthouse accessibility audit
- Keyboard-only navigation test

VERIFICATION
Lighthouse accessibility score ≥ 90
axe-core: 0 critical/serious issues
Complete user journey with keyboard only
```
