```text

  
  ROLE
QA Engineer setting up test infrastructure.

CONTEXT
Project: {{productName}}
All features complete (M1-M10).
Need testing framework setup.

OBJECTIVE
Configure testing infrastructure for unit, integration, and E2E tests.

REQUIREMENTS

1. Install testing packages:
- vitest (unit/integration tests)
- @testing-library/react
- @playwright/test (E2E tests)
- msw (API mocking)

2. Configure Vitest (vitest.config.ts):
- Setup files for React Testing Library
- Path aliases matching tsconfig
- Coverage thresholds

3. Configure Playwright (playwright.config.ts):
- Base URL for local dev server
- Browser configuration (chromium at minimum)
- Screenshot on failure

4. Setup test utilities:
- src/test/setup.ts: Global test setup
- src/test/utils.tsx: Custom render with providers
- src/test/mocks/: MSW handlers

5. Add npm scripts:
- "test": "vitest"
- "test:e2e": "playwright test"
- "test:coverage": "vitest --coverage"

VERIFICATION
npm run test — runs without errors
npm run test:e2e — Playwright opens browser
```
