```text

  
  ROLE
Frontend Developer implementing error handling.

CONTEXT
Project: {{productName}}
All features complete (M1-M9).
Need graceful error handling throughout the app.

OBJECTIVE
Implement error boundaries and error UI components.

REQUIREMENTS

1. Root error boundary (src/app/error.tsx):
- Catch unhandled errors
- Log error to error tracking service
- Display user-friendly error message
- Provide "Try again" and "Go home" actions

2. Feature-level error boundaries:
- src/app/(app)/dashboard/error.tsx
- src/app/(app)/{{feature}}/error.tsx
- Contextual error messages for each section

3. Not found pages:
- src/app/not-found.tsx (global 404)
- Feature-specific not-found.tsx where needed

4. Error UI components (src/components/ui/):
- ErrorCard: Reusable error display
- ErrorMessage: Inline error text
- RetryButton: Trigger error recovery

5. API error handling:
- Consistent error response format
- Map API errors to user-friendly messages
- Don't expose internal error details to users

VERIFICATION
Throw test error — error boundary catches it
Visit nonexistent URL — 404 page shows
No raw error messages visible to users
```
