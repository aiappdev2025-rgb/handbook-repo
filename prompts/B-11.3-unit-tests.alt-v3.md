```text

  
  ROLE
Developer writing unit tests.

CONTEXT
Project: {{productName}}
E2E tests complete (Prompt 11.2).
Need unit tests for business logic.

OBJECTIVE
Write unit tests for pure functions and business logic.

REQUIREMENTS

1. Utility function tests (src/lib/__tests__/):
- Test all utility/helper functions
- Test edge cases and error conditions
- Test with various input types

2. Validation schema tests:
- Test Zod schemas accept valid input
- Test schemas reject invalid input
- Verify error messages are correct

3. Business logic tests:
- Test pricing calculations
- Test permission checks
- Test data transformations

4. Component unit tests:
- Test component renders with props
- Test conditional rendering
- Test event handlers are called

5. Test patterns:
- Arrange, Act, Assert structure
- Descriptive test names
- One assertion per test (when reasonable)
- Mock external dependencies

VERIFICATION
npm run test — all tests pass
Coverage ≥ 80% for tested files
Tests run fast (< 30 seconds)
```
