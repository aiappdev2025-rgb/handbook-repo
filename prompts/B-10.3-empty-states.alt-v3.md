```text

  
  ROLE
UX Developer auditing empty states.

CONTEXT
Project: {{productName}}
Loading states done (Prompt 10.2).
New users see empty lists everywhere.

OBJECTIVE
Create helpful empty states for all data views.

REQUIREMENTS

1. Identify all empty state locations:
- Dashboard with no data
- Lists with no items
- Search with no results
- Filtered view with no matches

2. Empty state component (src/components/ui/empty-state.tsx):
- Icon (contextual)
- Title (what's empty)
- Description (why and what to do)
- Action button (create first item)

3. First-run experience:
- New user dashboard: Getting started guide
- First item prompts: Encouraging copy
- Quick actions to create content

4. Search empty states:
- No results: Suggest modifications
- Clear filters button
- Alternative actions

5. Zero state illustrations (optional):
- Simple, on-brand illustrations
- Don't over-design — simple is fine

VERIFICATION
Create new account — empty states guide user
Clear all data — no blank screens
Search nonsense — helpful message appears
```
