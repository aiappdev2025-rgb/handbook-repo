```text

  
  ROLE
Frontend Developer creating the admin console shell.

CONTEXT
Admin access control is implemented (Prompt 7.1 complete).
Design system is available (shadcn components).
Creating the admin-specific layout and navigation.

OBJECTIVE
Create the admin console layout with sidebar navigation.

REQUIREMENTS

1. Create admin layout (src/app/admin/layout.tsx):
- Server Component that verifies admin access
- Sidebar navigation on left (collapsible on mobile)
- Header with admin indicator and user menu
- Main content area with max-width container
- Visual distinction from regular app (different accent color)

2. Create admin navigation (src/components/admin/admin-nav.tsx):
- Dashboard link (overview/home)
- Users section
- Subscriptions section
- Error Logs section
- Settings section (for super_admin only)
- "Back to App" link at bottom
- Visual indicator for current section

3. Create admin header (src/components/admin/admin-header.tsx):
- "Admin Console" title/badge
- Breadcrumb showing current location
- User menu with logout
- Mobile menu toggle

4. Create admin dashboard page (src/app/admin/page.tsx):
- Overview stats: Total users, Active subscriptions, MRR, Recent errors
- Quick links to common actions
- Recent activity feed (from audit log)

5. Navigation configuration (src/lib/constants/admin-navigation.ts):
- Define nav items with: label, href, icon, requiredRole
- Some items only visible to super_admin

QUALITY STANDARDS
Layout clearly distinguishable from regular app
Navigation is responsive (drawer on mobile)
Current section highlighted in nav
Role-based nav items (some only for super_admin)
Components under 100 lines each

DELIVERABLES
1. src/app/admin/layout.tsx
2. src/app/admin/page.tsx (dashboard)
3. src/components/admin/admin-nav.tsx
4. src/components/admin/admin-header.tsx
5. src/lib/constants/admin-navigation.ts

VERIFICATION
1. Visit /admin as admin → dashboard renders
2. Navigation shows all sections
3. Mobile: hamburger menu works
4. "Back to App" returns to /dashboard
5. Super-admin-only items hidden from regular admin
```
