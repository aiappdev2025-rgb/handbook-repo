📘 AI SaaS Handbook v3.0 HUB

Purpose: Strategic hub containing methodology, Build Contract, MOAI integration overview, quality standards, infrastructure setup, and navigation to companion guides.

Contains: Research → Business Planning → Design Brief → UX/UI → Architecture → Build Contract → Infrastructure Setup → Multi-Environment Config → Build Overview → QA & Launch

📖 Use This When...

  • Starting a new project (read cover-to-cover first time)
  • Need to understand the methodology and "why" behind decisions
  • Generating a Build Contract from design artifacts
  • Setting up infrastructure (GitHub, Supabase, Vercel, environments)
  • Checking quality standards and verification criteria
  • Looking up which companion guide to use next

🔧 Build Phase Guide v3 COMPANION

Purpose: Tactical execution guide with SPEC templates, TDD prompts, and copy-paste instructions for every build milestone. Detailed, step-by-step instructions for Claude Code CLI.

Contains: SPEC Templates → TDD Workflow → 11 Milestone prompts → Admin Console implementation → Quality gates → Refactoring audit prompts → Code review prompts

📖 Use This When...

  • Ready to start coding (after Build Contract is generated)
  • Writing SPEC documents for features
  • Following TDD cycle (RED-GREEN-REFACTOR)
  • Need the exact prompt to paste into Claude Code CLI
  • Building Admin Console functionality
  • Running quality gate checks between milestones

🔄 Workflow Guide v1 NEW

Purpose: Context management, agentic patterns, and efficient development with Claude Code. Essential for managing large projects across multiple sessions.

Contains: Context Window Mental Model → CLAUDE.md Structure → Task Decomposition → Session Rhythm → MCP Tools → Git Workflow

📖 Use This When...

  • Setting up a new project's CLAUDE.md file
  • Managing context across long development sessions
  • Breaking down large features into manageable tasks
  • Establishing session rhythm with /clear tactics
  • Integrating MCP tools for memory persistence
  • Optimizing Claude Code CLI efficiency
