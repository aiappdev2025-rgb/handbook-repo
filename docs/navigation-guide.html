1.1 The Complete Document Set

Understanding what each document provides helps you navigate efficiently. Each document serves a specific purpose in your project workflow.

📘 AI SaaS Handbook v3.0 HUB

Purpose: Strategic hub containing methodology, Build Contract, development environment setup, quality standards, and navigation to companion guides.

Contains: Research → Business Planning → Design Brief → UX/UI → Architecture → Build Contract → Dev Environment Setup (CLAUDE.md) → Build Overview → QA & Launch

📖 Use This When...

  • Starting a new project (follow Parts I through IV-C sequentially)
  • Need to understand the methodology and "why" behind decisions
  • Generating a Build Contract from design artifacts
  • Setting up your development environment (Part IV-C)
  • Creating your CLAUDE.md file and docs/ folder structure
  • Checking quality standards and verification criteria

🔧 Build Phase Guide v3 COMPANION

Purpose: Tactical execution guide with SPEC templates, TDD prompts, and copy-paste instructions for every build milestone. Detailed, step-by-step instructions for Claude Code CLI.

Contains: SPEC Templates → TDD Workflow → 11 Milestone prompts → Admin Console implementation → Quality gates → Refactoring audit prompts → Code review prompts

📖 Use This When...

  • Ready to start coding (after completing Part IV-C setup)
  • Writing SPEC documents for features
  • Following TDD cycle (RED-GREEN-REFACTOR)
  • Need the exact prompt to paste into Claude Code CLI
  • Building Admin Console functionality
  • Running quality gate checks between milestones

🔄 Workflow Guide v1 REFERENCE

Purpose: Deep-dive reference for context management and advanced Claude Code patterns. Consult when you need efficiency optimizations during the Build Phase.

Contains: Context Window Mental Model → Advanced CLAUDE.md Patterns → Task Decomposition → Session Rhythm → /clear Tactics → Multi-Session Continuity

📖 Use This When...

  • Context window is filling up and you need /clear tactics
  • Working on a large milestone that spans multiple sessions
  • Breaking down complex features into manageable tasks
  • Troubleshooting context-related issues
  • Want to understand the "why" behind context management
  • Optimizing Claude Code CLI efficiency beyond the basics
