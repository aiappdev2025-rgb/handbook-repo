Chapter 31: Checkpoint A - Foundation Audit

This checkpoint ensures your foundation (M1-M3) is solid before building features on top. Skipping this risks security vulnerabilities and technical debt that compound as you build.

Checkpoint A: Foundation Audit

When: After completing Milestone 3 (Database)

Purpose: Verify security, schema integrity, and code quality before proceeding

Outcome: Git tag checkpoint-a marks verified foundation

31.1 Security Verification

RLS Policy Audit

Every table must have Row Level Security enabled. Run this query to verify:

-- List all tables and their RLS status SELECT schemaname, tablename, rowsecurity FROM pg_tables WHERE schemaname = 'public'; -- All tables should show rowsecurity = true

Policy Testing

Test that policies actually block unauthorized access:

-- Test as anonymous user (should return 0 rows) SET LOCAL ROLE anon; SELECT * FROM profiles; -- Test as authenticated user (should return only their data) SET LOCAL ROLE authenticated; SET LOCAL request.jwt.claims = '{"sub": "test-user-id"}'; SELECT * FROM user_owned_table;

RLS Checklist

  • RLS enabled on ALL tables (no exceptions)
  • Profiles table: users can only read/update their own
  • User-owned tables: CRUD restricted to owner (auth.uid())
  • No policies allow anon access to sensitive data
  • is_admin() helper function created

31.2 Schema Review

Data Integrity Check

Schema Checklist

  • Profiles table references auth.users with ON DELETE CASCADE
  • All user-owned tables have user_id foreign key
  • created_at and updated_at on all tables
  • updated_at trigger applied to all relevant tables
  • Appropriate indexes on foreign keys and query patterns
  • No nullable columns that should be required

31.3 Code Quality Check

Run all quality checks before proceeding:

# Build - should complete with no errors npm run build # Lint - should pass with no warnings npm run lint # Type check (if separate from build) npx tsc --noEmit # Check for security vulnerabilities npm audit

Code Quality Checklist

  • npm run build completes with no errors
  • npm run lint passes with no warnings
  • No TypeScript errors
  • npm audit shows no critical vulnerabilities

31.4 Tag the Checkpoint

Once all checks pass, tag this checkpoint in Git:

# Commit any pending changes git add . git commit -m "Complete Checkpoint A: Foundation verified" # Tag the checkpoint git tag -a checkpoint-a -m "Checkpoint A: Foundation audit complete - M1-M3 verified" # Push tag to remote git push origin checkpoint-a

Checkpoint A Complete

  • All quality checks passing
